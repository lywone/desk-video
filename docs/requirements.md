# Desk-Video 桌面讲解录制工具 — 需求分析 v0.2

> 目标用户：讲师/教程作者，录制"屏幕 + 讲解声音"型课程视频。
> 运行环境：Windows 桌面端，无独立独显的笔记本。
>
> v0.2 变更：**摄像头画中画、标注工具条（画笔/箭头/聚光灯）全部提前到 MVP**。

---

## 一、核心场景拆解

一节讲解课视频的录制 = 以下信号叠加成一条成片：

| 信号 | 说明 | 是否必需 |
|---|---|---|
| 屏幕画面 | 全屏 / 指定窗口 / 自定义区域，支持多显示器 | 必需 |
| 讲师人声 | 麦克风，含降噪需求 | 必需 |
| 系统声音 | 课件播放音、代码演示音效（WASAPI 回环） | 必需 |
| 讲师人像 | 摄像头画中画，可拖拽/缩放 | **MVP** |
| 标注强调 | 画笔、箭头、矩形、聚光灯、鼠标点击波纹 | **MVP** |
| 后期修整 | 去停顿、裁头尾 | 必需 |

---

## 二、功能模块（按优先级分层）

### P0 — MVP（第一版必须有）

1. **录制区域选择**
   - 全屏 / 指定应用窗口 / 框选自定义区域；多显示器可指定
2. **音频采集与混合**
   - 麦克风（echoCancellation / noiseSuppression / autoGainControl）
   - 系统声音回环（Windows WASAPI loopback）
   - 两路独立音量条，可分别静音
3. **录制控制**
   - 开始 / 暂停 / 继续 / 停止
   - 全局热键（最小化到托盘也能触发）：默认 `F9` 启停、`F10` 停止
   - 3 秒倒计时开始
   - 录制中显示：时长、文件大小、磁盘预估
4. **摄像头画中画**
   - 悬浮窗可拖拽、缩放、圆角/圆形
   - 可选摄像头源、预览
   - 录制中自动叠加到成片右下角（位置可在设置里选四角）
5. **标注工具条**（讲解课灵魂）
   - 画笔 / 荧光笔 / 箭头 / 矩形 / 文字 / 橡皮擦 / 清屏
   - 笔色、粗细可选
   - **标注烧录进视频**（与屏幕帧同帧合成）
   - 工具条本身 always-on-top，可拖动，不被录进成片
6. **鼠标强调**
   - 左键点击波纹圈
   - 聚光灯模式：屏幕压暗，只亮光标周围圆形区域
7. **输出**
   - MP4（H.264 + AAC）
   - 预设：720p30 / 1080p30（软编码 x264，码率 4–8 Mbps）
   - 每 10 分钟自动分段，防崩溃全丢
8. **录制后**
   - 弹出预览窗口，拖动滑块裁掉头尾
   - 一键复制到指定输出目录

### P1 — 第二版

9. 人声降噪（RNNoise 级离线降噪）
10. 片头片尾模板拼接
11. 暂停时间点自动写章节文件（.chapters），方便后期剪停顿
12. 快速 GIF / 短视频片段导出

### P2 — 远期

## 三、技术栈（已定）

- **Electron + Vue 3 + TypeScript**
- **Vite** 构建
- **ffmpeg sidecar**（系统声音回环 + 兜底转码）
- **Zustand / Pinia** 状态管理
- 不引入 Tauri（MVP 阶段）

## 四、无独显约束

- 软编码 x264，默认 720p30
- 1080p30 作为可选预设，CPU 占比 ~15–30%
- 每 10 分钟分段，崩溃最多丢最后一段
