# Desk-Video 使用文档

> 版本：v0.1（对应 MVP 需求 v0.2）
> 适用环境：Windows 10/11，Electron 桌面应用

---

## 1. 启动与退出

**启动**

```powershell
npm run dev      # 开发模式
# 或
npm run build && npm run start   # 运行构建产物
```

**打包安装包**

```powershell
npm run dist
```

产出 `release\Desk-Video-Setup-<版本>.exe`（NSIS 安装包，可选安装目录、生成桌面/开始菜单快捷方式）。安装版与 dev 行为一致：ffmpeg 随包解压到 `app.asar.unpacked`，首次打包需联网下载 electron 发行包（已配置 npmmirror 镜像）。

> 在 TRAE IDE 内置终端启动需加：`npx electron-vite dev -- --user-data-dir=D:\code\desk-video\.userdata-smoke`

启动后：

- 桌面出现 **Desk-Video 控制面板**（主操作窗口）
- 屏幕顶部中央出现**标注工具条**（可拖动，不会被录进视频）
- 系统托盘出现 Desk-Video 图标（点图标 = 显示/隐藏面板）

**退出**：托盘图标右键 → 退出。直接点面板 ✕ 只是隐藏到托盘。

## 2. 录制前准备

### 2.1 选择录制源（重要）

点击面板 **「录制源」卡片右上角的「更换…」按钮**，在弹窗中选择：

| 标签页 | 内容 | 建议 |
|---|---|---|
| 屏幕 | 所有显示器缩略图 | 录制整个屏幕，讲 PPT/全屏演示选这个 |
| 窗口 | 所有应用窗口缩略图 | 只录某个应用（如浏览器、PPT 放映窗口） |

点击缩略图即完成选择，面板会显示当前源名称。

> 不选择直接开始也可以：会**自动录制主显示器**（多显示器用户如需录副屏，请手动选）。
> 自定义框选区域暂不支持（MVP 约定：全屏录制 + 后期裁剪）。

### 2.2 音频设置

「音频」卡片两行独立控制：

- **麦克风**：讲师人声。开关 + 音量滑条，右侧绿色电平条说话时会跳动
- **系统声音**：课件音效、视频播放声。开关 + 音量滑条，蓝色电平条

录制中不能改开关，但可以随时拖音量。

### 2.3 输出设置

「输出」卡片 → 「设置…」按钮：

| 项 | 说明 | 默认 |
|---|---|---|
| 输出目录 | MP4 存放位置 | `视频\desk-video` |
| 分辨率 | 720p / 1080p / 1440p(2K) / 2160p(4K) / 跟随屏幕原始 | 720p |
| 视频码率 | 4–16 Mbps（高分辨率建议 12/16） | 6 |
| 分段时长 | 每 N 分钟自动存一个文件，防崩溃全丢 | 10 |
| 倒计时 | 开始前秒数 | 3 秒 |
| 摄像头 PIP | 位置四角 / 大小 / 开关 | 右下 25% |
| 录制时隐藏面板 | 开始录制后面板自动收起 | 开 |

## 3. 录制操作

### 3.1 基本流程

1. 面板点 **「● 开始录制」**
2. 屏幕中央出现 **3 秒大数字倒计时**（倒计时不会录进视频）
3. 倒计时结束进入录制（面板按设置自动隐藏）
4. 讲解过程中可用下方所有工具
5. 结束时按 **「■ 停止」** 或 **F10**
6. 收尾约 1–2 秒（webm 转 mp4），完成后**自动弹出预览裁剪窗口**

### 3.2 全局热键（面板隐藏时也能用）

| 热键 | 功能 |
|---|---|
| **F9** | 开始 / 暂停 / 继续 |
| **F10** | 停止 |
| **F8** | 摄像头画中画显示 / 隐藏 |

### 3.3 录制中的面板信息

若未隐藏面板可看到：时长、已录制大小、分段数、磁盘剩余。

## 4. 标注工具条（屏幕顶部悬浮条）

从左到右：

| 控件 | 功能 |
|---|---|
| ⠿ | **拖动手柄**——按住可把工具条拖到任意位置 |
| 🖱 选择 | 默认模式：不标注，鼠标穿透到桌面，不影响正常操作 |
| ✏️ 画笔 | 自由画线（标注默认红色） |
| 🖍 荧光笔 | 半透明粗线，适合划重点 |
| ➡️ 箭头 | 按住拖拽画箭头 |
| ▭ 矩形 | 按住拖拽画方框 |
| 🅣 文字 | 点击屏幕某处 → 输入文字 → 回车确认（Esc 取消） |
| 🧽 橡皮 | 点击某个标注整条删除 |
| 颜色圆点 | 红/黄/绿/蓝/白 五色快捷 |
| 三种圆点 | 粗细三档 |
| 🔦 聚光灯 | 屏幕压暗，只亮光标周围圆形区域（再点关闭） |
| ↩️ 撤销 | 撤销上一笔 |
| 🗑 清屏 | 清除全部标注 |

**要点**：

- 选 🖱 之外的任意工具后，鼠标就开始作画；画完想正常操作电脑，**必须切回 🖱**
- 所有标注会**实时烧录进视频**（与画面同帧合成）
- 工具条本身不会出现在录制结果里

## 5. 摄像头画中画（PIP）

> 面板上有**「摄像头」卡片**，勾选「画中画」即开启（会立即尝试连接摄像头；失败时顶部错误栏会显示原因：未检测到设备 / 权限被拒 / 被占用）。

- 位置（右下/左下/右上/左上）和头像大小在「输出 → 设置…」里调
- 录制中按 **F8** 或面板「隐藏画面」按钮随时显隐
- 画面为**圆形头像**（默认直径约屏高 16%，视频居中裁切、取景略上移），带细白边

---

## 6. 录制后：预览与裁剪

停止录制后自动弹出预览窗口（也可从「最近输出」的文件路径找到）：

1. 视频预览播放
2. 拖动**起点/终点两个滑块**裁掉头尾（如开头的手忙脚乱、结尾的鼠标乱晃）——**点击「起点/终点」时间文字或拖动滑块**，视频都会自动跳到该时间点并**从此处播放**（终点跳到切点前一帧），边看边对齐切点
3. 点 **「✂ 裁剪并另存」**——ffmpeg 原样裁剪（无损，秒级完成），生成新文件
4. 「打开文件夹」直达输出目录

> 分段说明：每 10 分钟（可配）自动存为 `rec_YYYYMMDD_HHmmss_001.mp4`、`_002.mp4`…，中途崩溃最多丢最后 1 秒。

## 7. 常见问题

**Q：点开始录制提示"请先选择录制源"？**
旧版本行为，现已改为自动选主屏；如仍出现说明未检测到显示器，检查显示设置。

**Q：系统声音电平条不动 / 录出来的视频没有系统声？**
应用优先随屏幕流抓取系统声（需在系统声音设置里确认输出设备正常）；失败会自动降级 ffmpeg WASAPI loopback。仍不行时检查：默认播放设备是否被独占模式占用（声音设置 → 设备属性 → 关闭"独占模式"）。

**Q：录制结果里出现两层标注/工具条？**
已修复（Windows 透明窗的捕获排除需要 show 后重设，见 implementation-steps 台账）。若复现请反馈，这是关键缺陷。

**Q：看不到摄像头画中画？**
摄像头默认关闭。到面板「设置…」里勾选「启用摄像头」后再开始录制；录制中用 F8 控制显隐。

**Q：画完标注后鼠标不能正常点击桌面？**
工具还停在画笔类工具上，切回工具条第一个 🖱 即恢复穿透。

**Q：文件为什么是先 .webm 再变 .mp4？**
为保证崩溃安全采用 webm 流式写盘，停止后自动 ffmpeg 无损转封装为 mp4（h264 时直接 remux，vp8/vp9 时自动转码），无需干预。

**Q：录制按钮变灰禁用，点了没反应？**
录制状态卡死或输出目录不可写。v0.1.1 起启动录制前会预检输出目录：不可写时面板顶部会直接显示原因（如「输出目录不可写： …」），状态自动回到可录制。常见于**从 IDE 内置终端启动 dev**——终端沙箱常禁止写 `视频\` 目录，两种解决办法：
1. 改用系统终端（PowerShell/CMD）运行 `npm run dev`；
2. 或在「设置…」里把输出目录改到项目目录内（如 `D:\code\desk-video\out-video`）。

若状态仍然卡死（极旧的构建），重启应用即可恢复。

**Q：录制后预览窗口黑屏/没有进度条、裁剪按钮不出现？**
已修复（dev 下 http 源加载本地文件被 Chromium 拦截，改用特权协议 rec:// 承载本地媒体，见 [recorded-protocol.ts](file:///d:/code/desk-video/electron/main/recorded-protocol.ts)）。若复现请反馈。

**Q：所有文件都留在 .webm、提示"部分文件转换失败"？**
多为 ffmpeg 组件损坏（下载不完整）。修复：
```powershell
Remove-Item node_modules\ffmpeg-static\ffmpeg.exe
$env:FFMPEG_BINARIES_URL="https://registry.npmmirror.com/-/binary/ffmpeg-static"
cd node_modules\ffmpeg-static; node install.js; cd ..\..
```

**Q：启动后整屏黑幕？**
已修复（overlay 背景透明化）。若复现请报告。

## 8. 快速上手 30 秒版

1. 启动 → 面板点「更换…」选屏幕（或直接开始=主屏）
2. 确认麦克风电平条会动
3. 按 **F9** → 倒计时 3 秒 → 开始讲
4. 需要强调时：顶部工具条选 ✏️ 画几笔 → 切回 🖱
5. 讲完按 **F10** → 预览窗口裁头尾 → 裁剪另存 → 打开文件夹拿 MP4
